## Key claims
- Encoder-decoder TS framework: latent bottleneck set attends to ALL input segments (temporal + cross-channel jointly); decoder uses learnable queries indexed by TARGET TIMESTAMP to retrieve information; trained on a generalised objective (extrapolation + interpolation + imputation with arbitrarily positioned segments).
- Code: github.com/efficient-learning-lab/TimePerceiver. Modality: forecasting benchmarks, not physiological.
- For EiV: already cited by H-E17 (pooling operators, refuted). The UNTESTED residual is the time-indexed QUERY decoder -- a momentary-state readout that asks 'what was the state at minute t' against the patch grid instead of pooling patches into a window vector. E29 measured the signal alive on the raw patch grid (AUC 0.6309, z+2.66, zero params) and dead after pooling (0.5202); a query decoder is the architecture that never pools.
