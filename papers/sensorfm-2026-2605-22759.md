## Key claims
- Architecture that wins in 2026: sensor foundation model (MAE-style reconstruction with latent bottleneck over ONE-MINUTE aggregated features from 5 modalities, 1e12 minutes / 5M people) -> frozen embeddings + PCA-50 + LINEAR heads -> Personal Health Agent that consumes the heads' PREDICTIONS. The LLM never reads the sensor stream; it reads predictions and daily metrics.
- Linear probes on frozen SensorFM-B embeddings beat supervised models trained on ENGINEERED FEATURES on 34/35 health tasks (cardio, metabolic, mental health incl. PHQ-8/PSS/anxiety, sleep, demographics). Scaling: joint data x capacity, near-linear; XXS shows dimensional collapse (90% variance in 20 PCs), B keeps a long tail. Heads found by agent search: 16/20 classification, 12/15 regression improved over linear; almost all winning heads reduce to 50-100 dims and are LINEAR.
- Agent evaluation (1,860 clinician ratings, Gemini 3 Flash, 31 real profiles): condition C = LLM given demographics + engineered daily metrics only is the WORST on all five rubric axes (p<0.001); condition A = same + SensorFM predictions is significantly better and statistically indistinguishable from condition B = same + ground-truth labels (p=0.396). No condition feeds the LLM raw sensor tokens at all.
- Limitations stated by the authors: Fitbit/Pixel only (transfer to other devices not guaranteed), one-minute aggregates discard beat-to-beat HRV, many labels self-reported/thresholded, single-turn agent evaluation, population = Fitbit users. Population-level, not within-person forecasting. No weights, code or data released.
- For EiV: the published bar a sensor encoder must clear is 'frozen embedding + linear head beats engineered features'; EiV's PL60 encoder currently LOSES to 15 handcrafted multi-scale features on momentary state (+0.085 vs +0.152). The narrator/agent architecture is the published product shape; soft-token injection into the LLM is not on the SensorFM path at all.
