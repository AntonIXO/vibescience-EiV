## Description
The Phase-C supervision surface: what shape of text the LM is trained to emit from the soft-token prefix. json_slots = a 13-key JSON schema with entropy in slot values (every shipped arm through 2026-08-17). chat_coach = prose annotation + mechanism + coaching action, with the same @@value@@ numeric atoms so grounding supervision is held constant. Distinct from `readout` (the decode stage) and from `prompt-parity` concerns: this is about the TARGET, not the decoder or the prompt.
