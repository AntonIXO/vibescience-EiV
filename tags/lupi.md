## Description
Learning Using Privileged Information (Vapnik & Vashist 2009): a signal available at TRAINING time only, used as an auxiliary target rather than an input. In optiHealth-EiV this is EDA, measured in 14 lab/clinical corpora and on no wrist device, supervising the encoder via privileged_weight and never entering the 12-channel tensor.
