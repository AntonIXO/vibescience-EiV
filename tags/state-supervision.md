## Description
Momentary / windowed affective-state supervision (flow / stress / neutral) in the EiV pipeline: state-head objectives (hard argmax CE, soft distributional CE, ordinal CORN), per-patch state supervision, transition-window evaluation designs, and the trait-vs-state decomposition. Distinct from `anomaly-detection` (outlier days) and from `jepa` (pretraining objective family).
